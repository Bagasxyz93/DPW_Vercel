## Deskripsi

Jobsheet 1 merupakan tahap awal pembuatan website SIMPUS-Mini menggunakan HTML. 
Pada tahap ini, website dibuat dengan struktur HTML dasar tanpa menggunakan CSS, sehingga tampilan masih menggunakan gaya bawaan dari browser.

Website terdiri dari beberapa halaman yang saling terhubung melalui navigasi, seperti halaman utama, daftar buku, tambah buku, daftar anggota, dan tambah anggota.
